# Ayah Snake previews

Real desktop/mobile browser captures with Al-Fatihah 1:1's first word collected by actual keyboard steering. The growing tail, active grid, source-backed distractors and exact Arabic are the real local UI. No mock account, generated Qur'anic text or fabricated saved progress is used.

Run Vite on port 5183, then `node scripts/snake-screenshots.mjs`. The script uses a paused browser clock to capture a stable frame of continuous gameplay.
